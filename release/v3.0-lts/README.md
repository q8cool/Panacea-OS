# Panacea OS Enterprise Version 3.0 LTS Package

This package establishes Long-Term Support for Panacea OS Enterprise Version 3.0.

## Contents

- `database/001_v3_lts_maintenance.sql`
- `openapi/panacea-v3-lts-maintenance.openapi.json`
- `policies/version-3-lts-policy.md`
- `policies/version-compatibility-matrix.md`
- `scripts/validate-lts-package.sh`
- `monitoring/lts-monitoring-catalog.md`
- `reports/lts-validation-summary.md`

## Boundaries

This package does not create a new service. It defines the LTS maintenance contract, persistence schema, audit/event model, API contract, validation package, and operational evidence for existing Version 3.0 services.
