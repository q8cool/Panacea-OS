# System Architecture Book

## Architecture Style

- Clean service boundaries for active v4 domains.
- PostgreSQL-backed persistence through service migrations.
- Event outbox pattern represented in migrations and runtime validation.
- Versioned REST contracts through OpenAPI.
- Foundation provider contract for identity, policy, audit, health, readiness, and metrics integration.
