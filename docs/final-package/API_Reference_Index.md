# API Reference Index

## Active OpenAPI Contracts

Service-level OpenAPI documents are stored in:

- `docs/contracts/openapi/`
- `services/*/docs/openapi.json`
- `release/v3.0/openapi/`
- `release/v3.0-lts/openapi/`

All active service paths are expected to remain versioned under `/api/v...` and validated by `npm run openapi`.
