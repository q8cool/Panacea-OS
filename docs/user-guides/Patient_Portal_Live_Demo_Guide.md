# Patient Portal Live Demo Guide

The Patient Portal workspace demonstrates what a patient or authorized caregiver can see in a safe, readable, patient-facing interface.

## Open

```text
http://localhost:5174/#/workspace/patient/dashboard
```

## Demo Pages

| Page | What You Can See |
|---|---|
| Dashboard | Upcoming care, message count, balance, medication count |
| Appointments | Synthetic appointments and clinic details |
| Visit History | Demo visit history |
| Medications | Medication schedule viewer |
| Lab Results | Patient-facing result list |
| Radiology Reports | Report summaries |
| Secure Messages | Demo inbox entries |
| Invoices / Payments | Invoice and balance visibility |
| Care Instructions | Educational care instructions |

## Patient Boundary

Patient-facing content does not replace clinician advice. The demo does not include real patient records, payment processing, telemedicine sessions, or live messaging.

## Live Mode

Patient Live Mode requires a valid Foundation-issued token with patient role and tenant claims. If live read APIs are not available, the UI keeps demo records clearly labeled.
