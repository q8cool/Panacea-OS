# Laboratory Workspace Guide

## Purpose

The Laboratory Workspace gives laboratory users a professional UI shell for lab orders, specimen tracking, collection, receiving, result entry, validation, approval, critical results, quality control, analytics, and reports.

## Open

```text
http://localhost:5174/#/workspace/laboratory/dashboard
```

Or use **Demo Role Switcher** and select **Laboratory User**.

## Pages

- Laboratory Dashboard.
- Lab Orders.
- Specimen Tracking.
- Specimen Collection.
- Specimen Receiving.
- Result Entry.
- Result Validation.
- Result Approval.
- Critical Results.
- Quality Control.
- Lab Analytics.
- Lab Reports.

## Visible Status Areas

- Order status.
- Specimen status.
- Turnaround time.
- Critical result flag.
- Validation and approval state.
- Auditability.
- Integration status.

## Data Mode

The workspace is read-only demo/operator mode using laboratory documentation, OpenAPI evidence, and command intelligence status.

Live laboratory workflow execution is not implemented in this UI sprint.

## What Requires Live Data

- Laboratory orders.
- Specimen accessioning.
- Result entry writes.
- Validation and approval writes.
- LIS/instrument integrations.
- Critical-result notification workflows.
