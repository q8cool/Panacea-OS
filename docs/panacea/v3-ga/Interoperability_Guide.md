# Version 3.0 Interoperability Guide

## Scope

Version 3.0 GA validates readiness for FHIR, HL7, DICOM, terminology mapping, national health exchange, cross-organization exchange, and cross-border exchange.

## Production Requirements

- Attach standards conformance evidence before regulated production exchange.
- Validate partner authentication and mTLS/API-signing controls where required.
- Confirm cross-border consent and data residency enforcement.
- Retain audit logs for every interoperability transaction.

## GA Position

The GA package includes interoperability readiness reporting. Environment-specific conformance lab evidence remains a deployment artifact.
