# Version 3.0.1 LTS Release Notes

## Release

Panacea OS Enterprise Version 3.0.1-LTS.

## Summary

This release establishes the Version 3.0 Long-Term Support maintenance contract. It does not introduce new business features, AI capabilities, services, autonomous diagnosis, autonomous treatment, or autonomous clinical decisions.

## Added

- LTS policy.
- PostgreSQL LTS maintenance migration.
- Versioned LTS OpenAPI contract.
- Maintenance and support documentation.
- Security maintenance and AI governance maintenance documentation.
- LTS package validation tests.

`v3.0.1-LTS`
