# GA Operations Guide

## Daily Operations

- Monitor health, readiness, and metrics endpoints.
- Review audit append success.
- Review event outbox processing.
- Track service errors and latency.
- Confirm Foundation provider availability.
- Review tenant-scoped access patterns.

## Incident Response

1. Classify incident severity.
2. Preserve logs and audit evidence.
3. Confirm tenant impact.
4. Use support bundle and diagnostic reports.
5. Follow approved rollback or restore process when needed.

## Evidence Retention

Keep release evidence, quality gate output, secret scan output, and runtime validation output with the approved release commit.
