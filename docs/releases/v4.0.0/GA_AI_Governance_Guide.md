# GA AI Governance Guide

## Governance Position

Panacea OS v4 intelligence workflows are advisory and governed. The system must not autonomously diagnose, prescribe treatment, or bypass required human approval.

## Required Review

- Validate recommendation governance rules.
- Validate approval workflow configuration.
- Validate unsafe output blocking.
- Validate traceability and evidence capture.
- Validate AI assurance and incident workflows.

## Production Promotion

AI models, prompts, tools, agents, and recommendation workflows require authorized approval before production use.
