# GA Privacy Guide

## Privacy Controls

- Consent-aware access is represented through provider policy contracts.
- Tenant isolation is enforced in service request handling and persistence.
- Audit evidence is required for sensitive actions.
- Cross-border processing must follow configured governance policies.

## Operator Requirements

- Configure country and region policies outside application code.
- Validate provider policy decisions before production traffic.
- Retain audit records according to organization policy.
