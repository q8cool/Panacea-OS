# Panacea OS v4 LTS Policy

## Purpose

The v4 LTS line maintains approved Panacea OS Enterprise v4 releases without introducing new business features, new healthcare modules, or new AI capabilities.

## Scope

- Security fixes
- Critical defect fixes
- Compatibility fixes
- Operational hardening
- Documentation corrections
- Release evidence maintenance

## Governance

All LTS changes require release-owner approval, audit evidence, and validation through the standard quality gate.
