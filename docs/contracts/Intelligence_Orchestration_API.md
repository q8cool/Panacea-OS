# Intelligence Orchestration API

## Base Path

`/api/v4/autonomous-healthcare-intelligence`

## Purpose

The Intelligence Orchestration API coordinates cross-platform intelligence records, enterprise context brokering, event routing, recommendation coordination, multi-domain decision registries, workflow controllers, and status dashboards.

The orchestration layer coordinates governed advisory intelligence. It does not execute clinical actions.

## Endpoints

- `POST /orchestration/orchestrators`
- `POST /orchestration/context-brokers`
- `POST /orchestration/event-routers`
- `POST /orchestration/recommendation-coordinators`
- `POST /orchestration/decision-registries`
- `POST /orchestration/workflow-controllers`
- `POST /orchestration/status-dashboard`
- `POST /integrations/references`

## Integrations

- AI Runtime v2
- AHOS Core
- Clinical Intelligence Platform
- AI Assurance Platform
- Privacy and Consent Platform
- Global Knowledge Network
- Enterprise Data Platform
- Audit Service
- Notification Service

## Required Controls

- Platform boundaries verified.
- Context broker policies checked.
- Event routing is auditable.
- Decision registry is governed.
- Workflow controller approval is recorded.
