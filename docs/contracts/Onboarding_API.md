# Onboarding API

The Onboarding API supports governed implementation and customer lifecycle onboarding workflows.

Endpoints:

| Endpoint | Purpose |
| --- | --- |
| `POST /api/v3/global-customer-success/onboarding/workflows` | Customer Onboarding Workflow |
| `POST /api/v3/global-customer-success/onboarding/implementation-projects` | Implementation Project Registry |
| `POST /api/v3/global-customer-success/onboarding/deployment-checklists` | Deployment Checklist |
| `POST /api/v3/global-customer-success/onboarding/configuration-checklists` | Configuration Checklist |
| `POST /api/v3/global-customer-success/onboarding/data-migration-checklists` | Data Migration Checklist |
| `POST /api/v3/global-customer-success/onboarding/training-checklists` | Training Checklist |
| `POST /api/v3/global-customer-success/onboarding/go-live-readiness` | Go-Live Readiness |
| `POST /api/v3/global-customer-success/onboarding/post-go-live-support` | Post-Go-Live Support |

Onboarding workflows require implementation governance approval, onboarding ownership, kickoff approval for started workflows, and go-live readiness plus post-go-live support controls for completed workflows.
