# Security Maintenance Guide v3

## Scope

Security maintenance includes CVE monitoring, dependency monitoring, security patch registry, certificate expiration monitoring, secret rotation scheduling, advisory tracking, hotfix workflow, and vulnerability remediation.

## Required Evidence

- CVE or advisory reference.
- Affected service and version.
- Severity and risk level.
- Remediation plan.
- Rollback plan.
- Validation evidence.
- Audit entry.

## Controls

Security maintenance uses identity, RBAC, ABAC, tenant isolation, global policy enforcement, audit, and support role permissions.
