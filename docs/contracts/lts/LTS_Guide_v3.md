# LTS Guide v3

## Scope

Panacea OS Enterprise Version 3.0 LTS is a maintenance-only support line for Version 3.0 GA. It supports patching, hotfixes, security maintenance, upgrade validation, rollback validation, diagnostics, support operations, global operations monitoring, and AI governance revalidation.

## Boundaries

- No new business features.
- No new AI capabilities.
- No new services.
- No autonomous diagnosis.
- No autonomous treatment.
- No autonomous clinical decisions.

## Required Controls

Every LTS action requires identity, RBAC, ABAC, tenant isolation, global policy enforcement, AI governance permissions when applicable, support role permissions, and audit persistence.

## Release Channels

- GA
- LTS
- Maintenance
- Security hotfix
- Emergency patch
